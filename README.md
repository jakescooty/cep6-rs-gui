# cep6-rs

## What is this?

A simple, lightweight, and fast Rust engine for the Cepstral line of TTS voice banks. **No voices are included**, you must supply your own copies.

## How to use

See the built-in help for usage instructions:
```sh
cargo build

./cep6 --help
```
